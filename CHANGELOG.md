# Changelog

## [0.1.0] - 2026-10-30

### Added

- Initial release as **LSA — Logical Systemd Aliases**
- `systemd-lsa.sh` with aliases across 5 groups: Service, Inspect, Logs, User Units, Power
- `lsa` built-in alias to display all aliases in a formatted table
- `systemd-lsa-help.sh` help script with box-drawing characters and ANSI colors
- `setup.sh` one-line installer and `setup-local.sh` installer for a local clone, both adding a `source` entry to `.bashrc`
- README with alias reference table and install instructions
